    Define registers in Python

    Registers are grouped into ordered collections known as addrMap's, represented by AddrMap class. When registers are added to the addrMap this ensures that they are unique (both, with regard to register names and addresses) within a given addrMap. Registers can be added to the addrMap at the time of construction or later by calling AddrMap::add(...) method.

    from rgscore import Register, AddrMap, FieldDef, EnumValue

addrMap = AddrMap(registers=[
    Register(
        bit_len=8,
        name="Foo",
        address=0x01,
        desc="Register Foo",
        model=[FieldDef.value_of("a@[3:0]U4.1#ro")]
    )
])

addrMap.add(Register(
    bit_len=8,
    name="Bar",
    address=0x02,
    model=[
        FieldDef.value_of("b@[3:0]U4.0#ro").with_description("field b").with_enum(
            [EnumValue("START", 1, "Starting..."), EnumValue("STOP", 0, "Stoping...")]
        )
    ],
))

    AddrMap ensures that registers do not have overlapping names or addresses.

    Class Register holds

    • name - optional human-readable name.
    • address - optional integer address within larger address space.
    • desc - optional description.
    • reset - reset value (default is 0x0)
    • bit_len - bit width.
    • address_bus_width_bytes - width of the address bus (default is 1).
    • model - optional model of register fields, i.e. an array of FieldDef instances.
    • link_provider - optional prover of RLink, object that links this register to the physical hardware.

    If model is None, then model with just one field spanning the whole of the register width is autogenerated with numerical type of unsigned int.

    When adding it to the AddrMap it must have an address. If name is not present, then adding it to the AddrMap will autogenerate name in the format R${hex_address}.

    Class FieldDef can be created using string description by calling FieldDef.value_of(...). Where description is

    {field_name}@{bit_range}{num_type}

or

{field_name}@{bit_range}{num_type}#{rw_flag}

    where {bit_range} is [{end_offset},{start_offset}]

    {num_type} is either a string "BCD" (i.e. Binary Coded Decimal) or a fixed point number definition in simplified Q_(number_format), i.e. U or S (for unsigned or signed) followed by bit-width, then dot, and then fraction.

    Flag {rw_flag} is optional and can be "rw" (default) or "ro".

    Description can be added by calling with_description(...) and enum values with_enum(...)
